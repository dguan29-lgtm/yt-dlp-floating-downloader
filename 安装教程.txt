yt-dlp Floating Downloader 3.6.0 安装教程
========================================

支持站点
--------
抖音、B站、YouTube、小红书、X/Twitter、Instagram、TikTok、新片场，以及 Liblib 页面中公开播放的 MP4。

安装
----
1. 完整解压 ZIP。
2. 双击“安装.cmd”。
3. 安装器会打开 Chrome 扩展页，并复制 extension 文件夹路径。
4. 开启“开发者模式” → “加载已解压的扩展程序” → 选择该 extension 文件夹。
5. 扩展 ID 应为：okbefieikffjgofllaokdgohmmbclfop
6. 打开扩展图标，先点击“检测本地组件”。

修改视频保存目录
----------------
在扩展 popup 中可以看到当前保存目录：
- 点击“选择文件夹”会打开 Windows 文件夹选择器；
- 选择后，后续新视频会保存到新目录；
- “恢复默认”会使用 Windows“下载\yt-dlp”；
- 已下载视频不会被移动。

新片场
------
请打开具体作品详情页，网址格式类似：
https://www.xinpianchang.com/a13770261
推荐页不是下载目标。若平台要求登录或返回 403，请确认你已登录且对作品有访问权；本工具不绕过平台权限。

Liblib
-----
仅支持页面中已经公开播放的 MP4 作品。鼠标移到具体视频画面时，只有检测到公开 MP4 才会显示下载按钮。私有、付费、DRM、blob/MSE、HLS/DASH 或没有公开 MP4 的内容不会提供下载。

故障排查
--------
- Service Worker 显示“无效”通常是 Chrome 空闲休眠，不是扩展损坏。
- 下载失败时先保留 PowerShell 窗口查看实际错误。
- 日志目录：%LOCALAPPDATA%\CherryYtDlp\runtime\logs
- 升级后在 chrome://extensions/ 点击扩展卡片的“重新加载”。
