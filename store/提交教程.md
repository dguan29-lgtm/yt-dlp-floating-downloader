# Chrome 应用商店提交教程

整个过程需要开着代理。审核一般几天到两三周。

## 0. 先合并 PR

隐私政策网址指向 main 分支的 `PRIVACY.md`，PR 合并后这个链接才能打开。

## 1. 生成上架包

```
python scripts/build_store_package.py
```

会生成 `dist/floating-video-downloader-chrome-store-<版本>.zip`。这个包去掉了 YouTube、manifest 里的 `key` 和 `tabs` 权限。以后发新版先改 `payload/extension/manifest.json` 里的 version，再重新运行这条命令。

## 2. 注册开发者账号（只做一次）

1. 打开 https://chrome.google.com/webstore/devconsole ，用你的 Google 账号登录。
2. 同意开发者协议，支付 5 美元注册费（Visa 或万事达卡）。
3. 在“帐号”页面填写发布者名称，并验证联系邮箱。

## 3. 上传

1. 点“新建内容”，上传第 1 步生成的 zip。
2. 上传后，地址栏里 `.../devconsole/.../` 后面那串 32 位小写字母就是商店扩展 ID。**把它发给 Devin**，或者自己填进 `scripts/Common.ps1` 的 `$script:StoreExtensionId = ''`，再重新打安装包。不填的话，商店版扩展连不上本地组件。

## 4. 填写资料

全部内容在 `store/listing.md` 里，按页面复制粘贴：

- **商品详情**：说明、类别、语言、图标、两张截图、宣传图块。
- **隐私权**：单一用途、每个权限的理由、远程代码选“否”、数据使用勾选、隐私政策网址。
- **分发**：建议先选“不公开（Unlisted）”。

## 5. 提交审核

点右上角“提交以供审核”。被拒的话，把邮件里的拒绝原因发给 Devin。

## 6. 给朋友用

1. 在商店里安装扩展。
2. 下载 Releases 里的安装包，运行 `安装.cmd` 装本地组件。安装结束时弹窗让你“加载已解压的扩展程序”，商店版用户可以忽略这一步。
